# expenshare
Pythson program that makes it simple to divide expenses, made with a grafical interface using tkinter (tricount was a source of inspiration - but discovered the existence of the app after the beggining of the project)

Just run the CODE3.0.py file in your IDE, and use the program as you please. It will generate a json file which will be saved in the same folder and will not be erased, so you can actually use it.

The json files in this repo are simply examples of the usage of the app and don't have any real need for you to pull.

Hope this saves you some peace of mind when dividing expenses at the end of a trip.

Project made during 2nd year of INSA engineering school
